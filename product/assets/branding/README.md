# Branding Assets

No final logo or icon is included because the product name and trademark are not yet decided.

Before public release provide:

```text
icon.svg source
Windows .ico variants
macOS .icns
installer artwork
license/source attribution for every asset
dark/light tray icons
```

Do not reuse Deskflow artwork in a way that makes the fork look like an official Deskflow release. Do not generate and commit a final brand before the product name has been checked.
