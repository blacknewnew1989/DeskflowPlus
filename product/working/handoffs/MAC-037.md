## Implementation

### macOS 权限与运行身份

- Deskflow 的 macOS 输入实现实际以 `AXIsProcessTrusted()` 判断输入捕获/控制能力；
  RelayDesk 现在让 Capture Input 与 Control Input 统一由 Accessibility 状态门控。
- Accessibility 已授权时，Input Monitoring 规范化为 `NotRequired`，避免界面在已具备真实
  输入能力时继续显示一个无法解除的阻塞项；Local Network 仍保持独立探测和指引。
- 权限提示、工具提示和紧凑首页摘要均指向真实阻塞能力，未新增自动弹出系统授权请求。
- 已定位旧本机测试包“系统设置开关已打开但仍显示 Blocked”的原因：其
  `CFBundleExecutable` 是 shell wrapper，随后 `exec` 到另一个 `RelayDesk.bin`；TCC 看到的
  实际执行身份与用户打开开关的外层 App 身份不一致。最终测试包必须让
  `CFBundleExecutable` 直接指向最终签名的 Mach-O，并在包内容固定后再完成一次授权。

### 紧凑首页、品牌、menu bar 与 lifecycle

- 紧凑单栏首页保留权限摘要、可信设备和传输入口，并新增用户始终可见的“暂停共享/
  继续共享”动作；动作替换时会断开旧连接，避免旧 QAction 再改写当前状态。
- 原创“双设备 + 中继点”品牌资源已由单一 SVG 派生并接入彩色 App/安装包与单色
  menu bar 使用路径。
- menu bar 菜单、窗口恢复、最小化/关闭到后台、一次性提示、暂停/继续共享和真正退出
  清理已接入现有主窗口生命周期。

### I18N-002

- 语言选择范围为 Deskflow 与 RelayDesk 两套 catalog 的交集：英语、简体中文、西班牙语、
  意大利语、日语、韩语和俄语。
- 设置页以稳定语言代码保存选择；选择后立即重载 translator、更新默认 locale 并持久化，
  无需重启应用。
- 活跃配对/接收错误不再缓存旧语言字符串，切换语言后会按当前 translator 重新生成文本。
- 七套 RelayDesk 语义 catalog 和七套完整 Deskflow catalog 已接入构建；本机构建 App 内已
  核对 7 个 Deskflow、7 个 RelayDesk、7 个 Qt，共 21 个 `.qm`。
