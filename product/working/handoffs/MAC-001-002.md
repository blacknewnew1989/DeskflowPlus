## Implementation

- Publishes the existing `PermissionSnapshot` contract; no duplicate UI type.
- Accessibility uses `AXIsProcessTrusted()` without prompting during status
  refresh.
- Input Monitoring uses `CGPreflightListenEventAccess()` without prompting
  during status refresh.
- Local Network uses an asynchronous Network.framework Bonjour browser. A ready
  browser is granted, DNS `kDNSServiceErr_PolicyDenied` is denied, and unrelated
  connectivity/fatal errors remain unknown with `ProbeUnavailable`.
- System prompts and System Settings deep links only run after an explicit UI
  action.
- Native diagnostics remain inside the probe. The existing UI model continues
  to expose only stable error codes and translated messages.
- The upstream macOS startup permission exit was removed so an unapproved app
  can display the actionable permission UI.
- Non-Apple builds use a conditionally compiled unavailable backend.
