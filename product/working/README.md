# Working Evidence Directory

When installed into the Deskflow repository, A0 creates and updates:

```text
product/working/
├── baseline-source.md
├── baseline-windows.md
├── baseline-macos.md
├── integration-map.actual.md
├── test-environments.md
├── decisions.log.md
└── baseline-results/
```

Do not place credentials, private keys, user files, full sensitive paths or large build artifacts here.
