# 07 UI/UX 规格

## 1. 原则

- 现代、清晰，不做传统“服务器配置表单堆砌”。
- 首页先显示设备和状态，技术端口放高级设置。
- 日常操作不要求理解 Server/Client，但高级页面保留与 Deskflow 兼容的角色配置。
- 传输失败必须告诉用户下一步，而不是只显示错误码。
- 中文为首要体验，同时保留英文 i18n。
- 动效短、可关闭，不影响键鼠响应。

## 2. 信息架构

```text
首页 / Devices
├── 当前设备
├── 已配对设备卡片
├── 发现的新设备
├── 屏幕相对布局
└── 快速发送

传输 / Transfers
├── 进行中
├── 等待接收
├── 已完成
└── 失败/可重试

设置 / Settings
├── 常规
├── 键鼠
├── 剪贴板
├── 文件传输
├── 发现与网络
├── 信任设备
├── 开机启动
└── 高级/日志

关于 / About
├── 版本
├── 上游与许可证
└── 诊断
```

## 3. 首页

### 顶部状态

```text
RelayDesk
本机：Windows-PC   已在线
键鼠共享：运行中
文件服务：运行中
```

状态只使用：

- 正常；
- 正在连接；
- 需要授权；
- 已暂停；
- 错误。

### 设备卡片

```text
┌─────────────────────────────────────┐
│ [Mac] MacBook Pro        在线  3ms  │
│ 已配对 · 右侧屏幕                   │
│                                     │
│ 把文件拖到这里发送                   │
│ [发送文件] [更多 ▾]                 │
└─────────────────────────────────────┘
```

卡片状态：

- discovered/unpaired；
- pairing；
- trusted/offline；
- trusted/online；
- trust violation；
- permission required；
- file transfer busy。

Drop feedback：

- hover 高亮；
- 显示文件数和总大小；
- 非本地文件/不可读项立即提示；
- 松开后进入准备清单，不直接无提示发送到陌生设备。

### 屏幕布局

复用/改进上游布局：

- 卡片可拖动相对位置；
- 显示当前主控；
- 显示跨屏边界；
- 支持上下左右；
- 防止完全重叠；
- 提供“自动排列”和“恢复默认”。

## 4. 配对向导

步骤：

1. 选择发现设备；
2. 双方确认设备名；
3. 显示/输入六位码；
4. 显示简短指纹；
5. 成功；
6. 可选设置自动接收和屏幕位置。

错误文案：

- “配对码已过期，请重新生成。”
- “对方证书已变化，为保护设备，已停止自动连接。”
- “多次输入错误，请稍后再试。”
- “两台设备不在可直连网络中，可使用手动地址。”

## 5. 发送流程

### 应用内拖放

1. 用户拖到设备卡片；
2. 本地异步扫描；
3. 弹出轻量确认：
   - 目标；
   - 文件/文件夹数；
   - 总大小；
   - 发现的不可读/不支持项；
4. 发送；
5. 首页卡片显示微型进度；
6. 传输中心显示详情。

已开启“对该信任设备自动接收”时，发送方仍显示已发送；接收方无需确认，但有系统通知。

### 快速发送

- 卡片按钮；
- 托盘菜单；
- 快捷键；
- 文件/文件夹选择器；
- 最近设备排序。

## 6. 接收流程

Incoming Offer：

```text
MacBook Pro 想发送
“Project”
42 个文件 · 1.2 GB

保存到：Downloads/RelayDesk
冲突：自动重命名

[拒绝] [更改设置] [接收]
[ ] 始终自动接收此设备的文件
```

安全：

- 不显示远端提供的富文本；
- 名称转义；
- 不自动打开；
- 未信任设备不会出现普通接收按钮，而是先配对。

## 7. 传输中心

每个任务：

- 方向图标；
- peer；
- 标题；
- 总进度；
- 当前文件；
- 已传/总字节；
- 速度；
- ETA；
- 状态；
- pause/resume/cancel/retry；
- 完成后“打开目录”。

状态文案：

```text
正在准备
等待对方确认
排队中
正在传输
已暂停
连接中断，等待恢复
正在校验
正在保存
已完成
已拒绝
已取消
失败
```

不要把 `RESUME_QUERY` 等协议名暴露给普通用户。

## 8. 设置

### 文件传输

- 默认接收目录；
- 接收策略：每次询问 / 信任设备自动接收；
- 冲突策略；
- 完成通知；
- partial 保留天数；
- 历史保留；
- 最大并发（高级）；
- 带宽限制（P1）。

### 信任设备

每台：

- 别名；
- 指纹；
- 自动接收；
- 最后在线；
- 撤销；
- 重新配对。

### 高级网络

- 发现开关；
- 手动地址；
- file port；
- 绑定接口；
- 代理：P0 不支持文件通道代理；
- 诊断连接。

## 9. 平台权限引导

### macOS

页面实时检测：

- Accessibility；
- Input Monitoring（按实际 OS/上游需求）；
- Local Network。

按钮打开系统设置；授权后重新检测。不能声称自动授予。

### Windows

- 防火墙允许；
- 管理员/UAC 能力限制说明；
- 自启动开关；
- 服务状态（仅上游实际存在时）。

## 10. i18n

使用语义 key：

```text
devices.status.online
pairing.code.expired
transfer.state.verifying
transfer.error.disk_full
transfer.action.open_folder
```

禁止将完整中文句子作为业务判断条件。

格式：

- 数量使用 plural；
- 文件大小本地化；
- ETA 本地化；
- 路径保持平台格式；
- 错误诊断可复制英文技术详情。

## 11. 可访问性

- 所有图标有 accessible name；
- 键盘可完成配对、发送、暂停；
- 焦点顺序合理；
- 不仅靠颜色表达状态；
- 进度条有文本；
- 支持系统高对比/减少动效；
- 字号遵循 Qt/system scaling。

## 12. 首版不做的 UI

- 社交账号头像；
- 云端设备列表；
- 团队/组织；
- 复杂统计大屏；
- 皮肤商城；
- 文件浏览器；
- 双栏同步器；
- 原生拖拽幽灵跨系统延续。
